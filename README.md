# MASARP STUDIO website + Rival Guys

Production-ready static site for **https://masarpstudio.com** on GitHub Pages.

## Main pages
- `index.html` — MASARP STUDIO homepage
- `rival-guys.html` — crawlable Rival Guys landing page
- `play-rival-guys.html` — full-screen playable game (`noindex`, canonical points to the landing page)
- `games.html` — studio portfolio
- `about.html` — studio/developer page
- `contact.html` — support and business contact
- `privacy.html` — privacy/ad disclosure
- `terms.html` — terms of use
- `404.html` — custom error page

## SEO included
- Canonical URLs using `masarpstudio.com`
- Unique title and meta description per indexable page
- Open Graph and Twitter metadata
- Organization, WebSite, CollectionPage, AboutPage, WebApplication/VideoGame JSON-LD
- `robots.txt`
- `sitemap.xml` with image entries
- 48px search favicon, `.ico`, Apple icon and PWA icons
- Internal navigation and descriptive crawlable page copy
- Fast static HTML/CSS landing pages around the WebGL game
- `CNAME` preconfigured for `masarpstudio.com`

See `DEPLOY_GITHUB.md`, `SEO_CHECKLIST.md`, and `ADS_SETUP.md` before launch.
